```yaml

type: principle
```

## p09 — 隔离景别非必要原则

```yaml
id: p09
title: 隔离景别非必要原则
type: principle
rejected_at: V3 (独特性)
reason: |
  "景别隔离不是必须的"是一个debunking（辟谣），
  它告诉你"不用遵循某规则"，但本身不是一个可操作的skill。
  更适合作为空间规则skill（s02）的边界条件——
  说明30°和180°原则的本质是"足够变化+逻辑一致"，景别只是手段之一。
retained_as: s02（镜头组接空间规则）的Boundary段。
```
