  type: case
  source_chapter: 00:05:58-00:06:26

    "这种闪回画面主要有三个部分组成：一人物，二时钟，三光影素材。

    演示了人眼感知时间表的实际应用。
  bound_to:
    - "人眼感知时间表"

- id: c06
  title: 快切卡点 vs 访谈口播的时长极端
  type: case
  source_chapter: 00:08:07-00:08:41
  source_quote: |
    "第一极端就是快切卡点，它完全用节奏接管的叙事，画面只需要迎合节奏，
    做视觉突击，不需要观众理解，杂乱细节，大脑被音乐带着走，
    音乐节奏间的时长决定了镜头的时长。
    第二极端就是访谈和口播的视频，它完全由语言逻辑接管的叙事，

  summary: |
    两种极端的时长控制方式：
    - 快切卡点：音乐节奏决定时长（<1.5s快切）
    - 访谈口播：语言逻辑决定时长（按内容需要）
    演示了镜头时长决策框架中"节奏控制"层面的两种极端。
  bound_to:
    - "镜头时长三层面决策框架"
    - "镜头时长=观众信息节奏控制原则"
  outcome: "两种极端各有适用场景，时长由不同因素决定。"
  tags: [case, duration, extreme, music-video, interview]

- id: c08
  title: 钥匙/动作顶点/遮挡点剪辑实例
  type: case
  source_chapter: 00:11:00-00:11:22
  source_quote: |
    "来看这个点就是在钥匙插完的结束点进行剪辑的。
    再看这个点，你可以说它是动作的顶点，但如果把它分解成两个动作，
    它就是第一个动作的结束点。包括这个这个这个都是结束点。
    然后这几个点，你可以说它是遮挡点又或是出画点，那归根结底就是主体的消失点。"
  summary: |
    多个剪辑点的归类演示：
    - 钥匙插完=结束点
    - 动作顶点=第一个动作的结束点
    - 遮挡点/出画点=消失点
    所有技巧归根结底都是"结束点"或"消失点"。
  bound_to:
    - "结束点/消失点剪辑原则"
  outcome: "统一的框架解释了看似不同的剪辑技巧。"
  tags: [case, cut-point, ending-point, disappearance-point]
