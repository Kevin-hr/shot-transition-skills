  type: framework
  source_chapter: 00:03:08-00:03:45
  source_quote: |
    "大家可以把屏幕想象成车窗，当车在行驶时，窗外的景物飞速后移，
    这时车窗范围内所有让你眼睛感到这画面变了的内容就是视觉变量。
    而视觉变量大的——奔跑、快速运镜、跳跃、甩头、挥拳、舞蹈——叫做动；
    视觉变量小的——呼吸、缓慢运镜、微笑、发呆、眨眼、风景——叫做静；
    完全没有视觉变量的就是定格。"
  summary: |
    用"画面内视觉变化量"替代传统的"动作镜头/固定镜头"分类来判断动接动静接近。
    核心转变：从"摄影机是否运动"转向"画面内是否有足够变化"。
    判断步骤：1) 识别画面内所有变化源（主体运动、运镜、光影）2) 评估变化量大小 3) 匹配同级别变化量的镜头。
  tags: [editing, visual-perception, categorization]

- id: f02
  title: 镜头时长三层面决策框架
  type: framework
  source_chapter: 00:05:39-00:05:45
  source_quote: |
    "我认为主要分三个层面：第一，信息获取；第二，情绪表达；第三，节奏控制。"
  summary: |
    确定镜头时长时，先判断当前镜头的目的属于哪个层面：
    1) 信息获取——让观众看清/看懂（基于人眼感知时间表给时长）
    2) 情绪表达——让观众沉浸/走心（长镜头给大脑时间消化情绪）
    3) 节奏控制——让观众紧张/兴奋（短镜头快切制造紧迫感）
    三个层面可叠加，但须分清主次。
  tags: [editing, duration, decision-framework, perception]

- id: f03
  title: 剪辑痕迹双策略框架
  type: framework
  source_chapter: 00:12:38-00:13:03
  source_quote: |
    "剪辑点的选择无非就两个思路：一，弱化剪辑痕迹，让画面过渡更丝滑；
    二，无视、无视、无视……甚至利用剪辑痕迹，突出你的想法。
    而弱化剪辑痕迹本质上也就两件事：一，转移注意力；二，逻辑自洽。"
  summary: |
    剪辑的元策略：先决定"对待剪辑痕迹的态度"。
    路线A（弱化痕迹）：通过转移注意力（动作、情绪、看点、声音）+ 逻辑自洽，让观众忽略切换。
    路线B（利用痕迹）：跳切/鬼畜等刻意打破连续性，用"跳"本身制造效果。
    决策路由：如果目标是叙事流畅→路线A；如果目标是制造张力/节奏感→路线B。
  tags: [editing, meta-strategy, cut-traces]

- id: f04
  title: "出势接作"剪辑框架
  type: framework
  source_chapter: 00:10:03-00:10:07
  source_quote: |
    "一个镜头负责出动势，一个镜头负责接动作。"
  summary: |
    动作剪辑的核心框架：不关注"切在哪一帧"或"比例多少"，
    而关注两个镜头各自承担的功能——前一个镜头制造动势（启动/蓄力），
    后一个镜头承接动作（完成/释放）。
    判断步骤：1) 识别动作的起始和完成 2) 在起始段选择"出势"帧 3) 在完成段选择"接作"帧 4) 在两帧之间切换。
    这个框架比"3:7比例"更本质，因为比例只是表象，出势接作才是原理。
  tags: [editing, action-cutting, core-principle]

- id: f05
  title: 人眼感知时间表
  type: framework
  source_chapter: 00:05:09-00:05:34
  source_quote: |
    "0.1到0.3秒，人的眼睛只能看到光影和颜色；0.3到0.5秒，能看清画面主体，
    但来不及理解画面关系；0.5到3秒，能完全看懂并理解画面里表达的内容；
    6到8秒，注意力就会衰减，无聊想滑走。"
  summary: |
    人眼获取画面信息有固定时间窗口：
    - 0.1-0.3s：仅感知光色（适合纯视觉冲击素材）
    - 0.3-0.5s：识别主体但不懂关系（适合辅助元素）
    - 0.5-3s：完全理解内容（适合主要叙事元素）
    - 6-8s：注意力衰减（镜头不宜超过此时长除非有特殊理由）
    用途：作为镜头时长决策的客观依据，替代"靠感觉定时长"。
  tags: [editing, perception, duration, cognitive-science]

- id: f06
  title: 镜头组接因果推理链
  type: framework
  source_chapter: 00:00:16-00:00:28
  source_quote: |
    "因为当视角几乎没变或者变化不大的时候，我们大脑会认为这是一个镜头，
    但主体却毫无征兆地变化了，大脑就会觉得逻辑不通，于是你就会觉得跳。"
  summary: |
    推理"为什么会跳"的因果链：
    视角变化不足 → 大脑判定"同一镜头" → 主体却变了 → 逻辑不通 → 感到"跳"
    这个推理链是30°和180°原则的理论基础。
    反向应用：要避免"跳"，要么让大脑识别出新镜头（足够变化），要么让变化符合逻辑（方向/速度/空间一致）。
  tags: [editing, perception, causation, cut-theory]
