## 这次剪辑踩到并修掉的两个坑

### 坑 1：同场景内方向相反（`transition-matching-dual-dimension`）

C1 与 C2 同属"街头"场景，但 C1 向左、C2 向右。观众看到孩子向左走、下一秒画面变成向右，
产生逻辑断裂。

**关键判断**：skill 规定"不同场景 → 跳过方向检查"，反向推论即"**同一场景 → 必须检查**"。
C1/C2 不满足跳过条件，所以这是真违规，不是误报。

**修复**：对 C2 素材水平翻转，两镜方向统一为"向左"。

### 坑 2：时长均匀化导致节奏单调（`shot-duration-decision`）

原始序列 `7→6→6→5→6→6→7` 全部挤在 5–7s，没有任何快切段落。两个活跃运动场景
（C3 台阶玩耍、C5 海滩泡泡）各留 6s，动感被抹平。

**修复**：活跃场景缩短至 3s、插入镜头缩短至 4s/3s → 波浪序列。

### 坑 3（工程）：xfade offset 未扣重叠，成片被截断

首次拼接时链式 `xfade` 的 `offset` 没有扣除转场重叠量，成片被截到 10.5s，
C3–C7 全部丢失却**误报成功**。

**教训**：`offset` 必须基于"扣除重叠后的累计时长"，且每次须 < 前一复合片段时长；
拼接后**必须核对最终时长 = Σ各段 − Σ转场**。
