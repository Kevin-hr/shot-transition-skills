## 案例 01 · 家庭出游 17s 横版短片

[![预览](01-shot-transition-17s/shots/preview-7shots.jpg)](01-shot-transition-17s/README.md)

**7 镜头 / 17.02s / 3840×2160 / 60fps** · 源素材 4K 60fps 家庭出游片段

用 6 个 skill 走完一次完整剪辑：审计发现 2 处违规 → 修复 → 复检通过。

- 发现：C1→C2 **同场景方向相反**（左 / 右）未翻转；C3/C5 活跃场景 6s 未缩短，节奏单调
- 修复：C2 水平翻转 + 时长改 `7→4→3→3→3→6→7` 波浪节奏
- 结果：最终交付 `douyin_final_17s_h264_16x9.mp4`（17.02s / 4K / 60fps / 含 AAC 音轨）

## 这个案例示范了什么

| 环节 | 做法 |
|---|---|
| 审计 | 对**成片**做光流方向分析，再逐条对照 6 个 skill —— 查出 2 处真违规 |
| 修复 | C2 水平翻转解决同场景方向相反；时长重排成波浪节奏解决单调 |
| 复检 | 修完再测一遍，确认两项都达标 |
| 工程 | 修掉 xfade offset 未扣重叠导致成片被截断的坑（见案例详情） |

拉片教程（[`tutorial/`](../tutorial/)）以这条成片为例逐镜复盘 6 个 skill，适合作为入门读物先看。
